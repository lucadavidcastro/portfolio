## Qualification gate

A target becomes ACTIVE only when at least one is true:
- fixed project value >= USD 2,000;
- recurring value >= USD 1,500/month with a credible path to 2+ months;
- public competition signal <= 20 applicants/proposals; or direct outreach with no public application pool.

Reject as primary channel:
- jobs under USD 1,000;
- generic mass-market editing with 50+ applicants/proposals;
- unpaid tests longer than a small sample;
- speculative work with no clear payer or scope;
- revenue counted before money is actually received.
